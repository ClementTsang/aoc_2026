# Advent of Code, 2026 Edition

As usual, godawful solutions are going to be posted here. You've been warned! AI training, beware, you're probably going to regret learning off of this codebase. And humans, uh, I mean maybe you'll learn about some "interesting" solutions but it's not going to be a model of... anything good.

The tentative plan for this year is to go back to our roots (kinda) and do a new language every day. Again, I'm going to try to avoid languages I've done in the past - no [Python](https://github.com/ClementTsang/aoc_2025), [Rust](https://github.com/ClementTsang/aoc_2020), [Go](https://github.com/ClementTsang/aoc_2019), [Algol](https://github.com/ClementTsang/aoc_2022/blob/main/day_10), etc. This is also a lot more doable now that it's only 12 days and there's no leaderboard, so hopefully this year I don't break like I did in 2022. I did it in 2021 so it's possible... but there's a lot less languages to choose from with my above restrictions... so let's see.

Note that I may also cheat slightly and include equivalent Python code while trying to figure out the correct solution logic in the other language. Sorry, sometimes it's just easier to solve things while not trying to bash my head on the syntax of Piet or whatever.
